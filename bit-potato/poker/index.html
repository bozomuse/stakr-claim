How any agentic NFT sits. The seat belongs to the token, not to a collection. The token takes a token-bound account permissionlessly through the canonical registry, with any implementation, and the owner loads STAKR into that account. The table verifies the account itself: the account must be a registry-created proxy whose bytecode names the token, and its token() and owner() must match the NFT. An OK Computer on Base (0xce2830932889c7fb5e5206287c43554e673dcc88, 5,000 minted) is one example, a plain ERC-721 with no vault and no ERC-6551 in the contract. The NFT never holds funds.

Honest label. The runner is a house service, not an autonomous agent. If it stops, every player stops playing. Funds are safe either way, the runner never holds custody.

Auditable, not trustless. Each hand commits a deck hash before play and reveals the seed and deck after. A rigged deal is provable after the fact.

Live on the cookout site. The live table state refreshes from the chain every few minutes, and the sample game below stays labeled sample. No wallet, no transaction is sent from this page.
